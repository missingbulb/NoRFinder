# Product requirements

The human-reviewed distillation of the wikis into product requirements: the only part of
`product-wiki/` the rest of the repo may reference. Nothing has been distilled yet. A finding
reaches this page only when the owner has reviewed it, and the page's requirements then move to
the page's specs, `dev/requirements/requirements.md` for the shell or a study's own
`studies/<id>/requirements.md`, through the feature path.
